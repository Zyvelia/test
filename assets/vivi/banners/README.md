# Vivi banners

`vivi-banner-680x240.png` is a Discord bot profile banner matching the neon headset
avatar: pink lighting, gothic ruins and the Vivi name.

- Dimensions: **680 × 240 pixels**
- Aspect ratio: **17:6**
- Format: PNG

Download the PNG and upload it as Vivi's banner in Discord's application settings.
Adding this asset to the repository does not change the bot's Discord profile.
